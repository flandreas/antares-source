=== Symbol editieren

Warum braucht es das überhaupt?

* Tannenbaum-CPU: MPC ist ein Standard-8-Bit-Register, das den Output-Value als Control anzeigt und den Clock-Eingang rechts statt links hat.

* Dito für A-Latch und B-Latch (Output-Value als Control, Clock-Eingang rechts)

* A-MUX: Keine Port-Labels, Select-Eingang rechts
