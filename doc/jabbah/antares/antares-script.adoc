=== DSL

==== CircuitViewBridge

Used in all `Scenario` use cases. The statements in the table below are accessible as functions of the object `circuit`.

|===
|Statement |Description |Example

|`name()`
|Returns the name of the circuit model.
|`circuit.name()`

|`input(<Name>)`
|Returns the signal of the `GraphInput with the specified name.
|`return circuit.input("I") == "1"`

|`output(<Name>)`
|Returns the signal of the `GraphOutput` with the specified name.
|`circuit.output("O")`

|`elem(<ID>)`
|Returns the `CircuitElemViewBridge` of the element with the specified ID.
|`val e = circuit.elem(42);`

|`scenario()`
|Returns the ID of the current `Scenario`, or an empty string if none is active.
|`val scenarioId = circuit.scenario();`

|`highlight(<ID>)`
|Highlights the element with the specified ID.
|`circuit.highlight(42);`

|`unhighlight()`
|Removes all highlights from the circuit.
|`circuit.unhighlight();`

|===
